# Create your first event type

Source: https://cal.com/help/event-types/create-first-event.md (fetched 2026-08-10, real Cal.com help article)

A quick walkthrough of how to create event types.

## The basics

Navigate to the **event types** page, then select the **New event type** button located in the top right corner.

The create event type dialog will appear, requesting essential information to establish a functional event type:

* Title
* URL (e.g. cal.com/bailey/**example-event**)
* Description
* Length

![New event type dialog](https://downloads.intercomcdn.com/i/o/1195433173/459d590315726cde2c3da6a6/i973x933.png)

These elements constitute the minimum requirements for launching an event type, though additional configuration options are available for enhanced customization.
